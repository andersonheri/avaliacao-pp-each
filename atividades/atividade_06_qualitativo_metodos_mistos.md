# Atividade 6 — Do número ao porquê: desenhando uma avaliação de métodos mistos

**Duração:** ~20 min (em grupos de 3–4 pessoas, salas simultâneas) + 10 min de plenária
**Material:** Batista e Domingos (2017), seções "Técnicas qualitativas" (pp. 14–18) e "Discussão: combinando métodos" (pp. 18–20), Figura 8.
**Não precisa de R.**

## Cenário

Uma avaliação de impacto (DiD) do programa **Qualifica** mostrou que a renda dos participantes
cresceu **R$ 300/mês** a mais que a do grupo de controle. Mas há três surpresas:

1. O efeito é **muito menor entre mulheres com filhos pequenos** (~R$ 80).
2. **35% dos inscritos abandonaram** o curso antes do fim.
3. Na pesquisa de satisfação, **80% dizem estar "muito satisfeitos"**, mas o gestor acha que
   "algo não bate".

## O que o grupo deve produzir (um slide ou uma folha)

**Parte A — A pergunta que cada técnica responde**

| Pergunta | Técnica mais adequada | Por quê? |
|---|---|---|
| Quanto o programa aumentou a renda? | | |
| Por que mulheres com filhos pequenos se beneficiam menos? | | |
| Como é, na prática, o dia a dia de quem faz o curso? | | |
| O que "satisfeito" significa para as pessoas? | | |

Opções: experimento/quase-experimento, **observação** (etnografia), **entrevistas em profundidade**,
**grupos focais**, survey.

**Parte B — Roteiro-guia**

Escrevam **4 perguntas abertas** para uma entrevista semiestruturada com mulheres que
abandonaram o curso. Lembrem (artigo, p. 16–17): perguntas abertas, que capturem
*percepções, significados e experiências*, sem induzir respostas.

**Parte C — Combinando métodos (Figura 8 do artigo)**

Classifiquem o desenho de vocês:

- ( ) **Coordenado**: métodos combinados no *final* para ilustrar/explicar achados;
- ( ) **Integrado**: métodos conversando desde o *desenho* dos instrumentos.

Justifiquem: o que a técnica **qualitativa** acrescenta ao número do DiD? E o que o DiD
acrescenta à história contada nas entrevistas? (Exemplos do artigo: Adato, 2008, PTCR na
Nicarágua; Hunter e Sugiyama, 2014, Bolsa Família.)

## Perguntas para a plenária

- Os métodos qualitativos *substituem* os quantitativos, *complementam* ou *respondem a outra pergunta*?
- Quais riscos (viés do entrevistador, reflexividade, representatividade) vocês enxergam no desenho que propuseram?
- Quem **deveria** entrar na amostra qualitativa? Como escolher sem "viés de conveniência"?
